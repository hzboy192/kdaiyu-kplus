
# k线模拟交易系统
    
## 简介

采用klinecharts绘制在web页面，用户可以手动逐根K线图播放，当用户进行模拟交易后记录点位，当用户卖出时记录点位，通过计算两次交易的点位差值计算用户的盈利。系统会存储用户所有交易记录数据，资金账户数据。将数据按多维度统计分析，以图表方式展现各种统计指标。为用户提供交易历史分析及交易策略评估提供参考。

## 统计分析模块

统计用户交易的盈利情况，交易次数，盈亏比，资金曲线，收益统计等指标。


## 账户管理

在用户默认交易账户之外还可以创建新的资金账户，允许创建多个，创建时给账户设置金额。可以在账户列表设置默认账户，禁用/启用账户，查看资金曲线等功能。

## 信息维护

开发登录用户信息维护功能，包括手机号绑定、邮箱绑定、密码修改、昵称修改、头像设置等等常见的账号信息维护。
